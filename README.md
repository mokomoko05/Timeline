# Timeline

Color your thread.

Timeline 是 macOS 原生任务管理应用。包含待办时间轴、月历、快速记录、专注计时、笔记与日记。无需账号，数据存储在本机。

## 界面

| 界面 | 内容与操作 |
| --- | --- |
| 主界面 | 待办按截止时间排列，月历显示日期分布。上下拖动任务圆点调整同一日期或 No Due 内的顺序；右键圆点选择优先级。将任务拖到日历日期格可修改截止日期；日历里的圆点也可拖回左侧日期分组，拖到 No Due 则清除日期。也可通过截止日期按钮或任务菜单修改。最右侧按钮标记完成，已完成、已放弃事项可折叠。 |
| 快速记录 | 独立输入面板，支持日志、待办与图片。`@` 关联任务，`#` 添加标签。 |
| 专注工作台 | 选择任务、设置目标与时长，计时期间记录笔记，结束后填写反馈。 |
| 笔记 / 日记 | 按任务、标签整理笔记，或按日期查看日志与专注记录。 |
| 内置终端 | 支持标签页与分屏。 |

## 快捷键

| 默认全局快捷键 | 界面 |
| --- | --- |
| `⌃⌥D` | 显示 / 隐藏主界面 |
| `⌃⌥L` | 快速记录 |
| `⌃⌥F` | 显示 / 隐藏专注工作台 |
| `⌃⌥N` | 打开 / 关闭笔记与日记 |
| `⌃Tab` | 显示 / 隐藏内置终端 |

`⌃` 为 Control，`⌥` 为 Option，`⌘` 为 Command。全局快捷键可在设置中修改。

| 界面内快捷键 | 操作 |
| --- | --- |
| `⌘Enter` | 提交输入或保存编辑 |
| `⌘T` | 主界面回到今天；终端新建标签页 |
| `⌘J` | 打开 / 关闭当天日志 |
| `⌘Z` / `⇧⌘Z` | 撤销 / 重做 |
| `⌘,` | 打开设置 |
