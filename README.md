# Timeline

Color your thread.

Timeline 是 macOS 原生任务管理应用。包含待办时间轴、月历、快速记录、专注计时、笔记与日记。无需账号，数据存储在本机。

## 界面

| 界面 | 内容与操作 |
| --- | --- |
| 主界面 | 待办按截止时间排列，月历显示日期分布。上下拖动任务圆点调整同一日期或 No Due 内的顺序；右键圆点选择优先级。将任务拖到日历日期格可修改截止日期；日历里的圆点也可拖回左侧日期分组，拖到 No Due 则清除日期。也可通过截止日期按钮或任务菜单修改。最右侧按钮标记完成，已完成、已放弃事项可折叠。 |
| 快速记录 | 独立输入面板，支持日志、待办与图片。`@` 关联任务，`#` 添加标签。 |
| 专注工作台 | 选择任务、设置目标与时长，计时期间记录笔记，结束后填写反馈。专注开始后菜单栏显示倒计时，隐藏工作台后仍可查看，点击计时可重新打开工作台或暂停、结束专注。 |
| 笔记 / 日记 | 按任务、标签整理笔记，或按日期查看日志与专注记录。双击正文编辑，`⌘Enter` 保存，`Esc` 取消；点击别处保留编辑状态。 |
| 工作板 | 每个待办或标签对应一页 Markdown，可自由编辑、选择和删除文本，切换预览查看标题、列表、代码与网页链接；⌘↩ 切换编辑 / 预览，内容自动保存。点击标题旁的星标固定到顶部常用栏，一键切换多个工作板；常用按钮仅显示名称，按住横向拖动时高亮并实时让位，松手保存顺序，Esc 取消；拖至栏边缘会自动滚动，也可右键向左 / 向右移动。浮窗与专注面板一样保持置顶，支持阅读 / 会议模板。任务的更多菜单和笔记页提供入口，任务 / 标签删除后内容保留在归档工作板中。 |
| 内置终端 | 支持标签页与分屏。 |

## 快捷键

| 默认全局快捷键 | 界面 |
| --- | --- |
| `⌃⌥D` | 显示 / 隐藏主界面 |
| `⌃⌥L` | 快速记录 |
| `⌃⌥F` | 显示 / 隐藏专注工作台 |
| `⌃⌥N` | 打开 / 关闭笔记与日记 |
| `⌃⌥M` | 显示 / 隐藏工作板 |
| `⌃Tab` | 显示 / 隐藏内置终端 |

`⌃` 为 Control，`⌥` 为 Option，`⌘` 为 Command。全局快捷键可在设置中修改。

点击任务的日期 / 时间入口，或选中任务后按 `D`，可打开统一的截止日期面板。全天任务显示「全天」，指定时间采用 24 小时制，可直接输入小时、分钟或选择常用时间；切换日期会保留时间。创建待办时使用相同的面板。

工作板随任务、日志一起备份和导出，数据格式升级为版本 8。旧工作板条目会按原顺序转换为 Markdown，保留完成状态、说明和链接；转换前自动备份原文件。旧版应用会停止写入新版文件，回退应用前请保留新版备份。

工作板中的 `- [ ]` / `- [x]` 会显示为可点击的圆圈，完成时显示绿色圆圈勾选和文字删除线，点击即可切换状态并自动保存 Markdown。任务和标签的笔记页会在标题下显示深色的「看板内容」区域；标签的「按待办」章节也显示对应任务的看板，空白内容不占位。笔记页与浮窗共用同一份内容，勾选实时同步；查找按任务 / 标签缓存索引，Markdown 解析与排版复用现有缓存，章节随滚动按需加载。

工作板底部提供「折叠内容」「论文阅读」「会议议程」三个模板按钮，点击即可插入。「折叠内容」会将选中的文字放进正文，并选中标题供修改。预览和笔记页收起时只显示一行标题，点击展开 Markdown 正文；支持嵌套和 `<details open>` 默认展开。折叠操作不会改写正文或新增笔记。

工作板默认使用编辑与预览合一的 Markdown 编辑器：当前段落显示语法，光标移开后就地渲染，无需快捷键切换。`#` 到 `######` 使用不同颜色并适配深浅外观；连续空行按原文保留。`<details>` 折叠即时响应，不播放高度动画，双击折叠标题可编辑标题。右上角 `</>` 可切到完整源码模式，光标与撤销历史保留；按住 `⌘` 点击链接可打开网页。

点击右上角 `Vim` 可开启或关闭 Vim 键位，选择会记住。支持普通、插入、可视模式，以及 `h/j/k/l`、`w/b`、`gg/G`、`dd`、`yy/p`、`u`、`Ctrl-R` 和 `/` 搜索；`i` 进入插入模式，`Esc` 返回普通模式。源码和实时预览使用同一编辑器，Vim 状态不会因自动保存而重置。

输入停顿后再批量同步，避免逐字刷新其他窗口，中文组词期间不回写正文。切换工作板、关闭或退出前读取最新编辑内容再保存；最近使用的工作板复用编辑器并保留光标。编辑器和 Vim 依赖随应用离线打包，应用构建无需 Node.js；修改编辑器脚本后，在 `Editor` 目录运行 `npm ci && npm run build` 更新打包资源。

```html
<details>
<summary>这里填写一行标题</summary>

在这里填写正文、[链接](https://example.com) 或待办：

- [ ] 阅读目标

</details>
```

| 界面内快捷键 | 操作 |
| --- | --- |
| `⌘Enter` | 提交输入或保存编辑 |
| `⌘T` | 主界面回到今天；终端新建标签页 |
| `⌘J` | 打开 / 关闭当天日志 |
| `⌘Z` / `⇧⌘Z` | 撤销 / 重做 |
| `⌘,` | 打开设置 |
