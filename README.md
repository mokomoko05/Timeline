# Scheduler

macOS 原生的待办、日志和笔记应用（SwiftUI / AppKit），数据全部保存在本机。

- **待办**：每个待办有永久编号 `#N`，不用做了可以「放弃」（留着记录，不算完成），可设高 / 普通 / 低优先级、截止日期及具体时间、提醒、重复，可加 `#标签`。直接写「明天 15:00 开会 提前30分钟」会自动识别。清单支持截止时间 / 优先级 / 手动排序，保留日期分组；拖动右侧把手自动切到手动排序。月历始终按日内截止时间排列，未指定时间的排在当天最后。点击任务左侧色点即可循环切换优先级：蓝色普通 → 橙色高 → 灰色低；右键和详情中也可直接选择。点截止时间可直接编辑。每行右边有 `#` 标签按钮、专注键、「三点」和把手：鼠标停在三点上展开成环形菜单（笔记、截止日期、标签、固定、放弃、删除），右键有同样的菜单；点清单以外的地方取消选中。选中一条待办后，键盘 `N` 笔记、`D` 截止日期、`T` 标签、`P` 固定、`X` 放弃、`F` 专注（「事项」菜单里也有）。清单顶部是「逾期 · 今天 · 未完成」摘要（点数字跳到分组）和今天的进度条。
- **专注计时**：按 `⌃⌥F` 打开常驻专注工作台，在里面选择未完成待办、输入本轮目标和专注时长（默认 25 分钟，可自定义）。开始后工作台停在屏幕右下角，显示剩余时间、目标和快速笔记输入；笔记回车后自动关联当前待办。待办里有链接的会在开始时打开或切换到已有页面，之后可以自由访问其他网页、终端和笔记，不会因为离开链接而自动结束；倒计时归零后暂停计时，原尺寸面板显示阶段反馈，可保存到当前待办笔记并结束、跳过结束或延长 5 分钟；任务完成、放弃、删除或应用退出时也会结束。计时进行时写的日志自动归到该待办名下；暂停时的普通记录不自动关联。专注不足 5 分钟（设置里可调，0 表示都记）不在日志里留「开始 / 结束」记录，用过的时间仍累加到任务上。
- **当天日志**：选中某一天按 `⌘J`（或日期旁的按钮；日历里选中的格子右上角、悬停的格子也有按钮）打开独立窗口，按时间顺序列出当天所有日志（打开时停在顶部，不自动滚动；自己写了新日志才会跟到那一条），可在里面写、改、删、关联待办、打标签、多选批量处理、复制（每条日志的按钮悬停时才浮出来，右键有完整菜单）；右边是当天复盘，单击即可编辑，也可一键按「进展 / 卡点 / 明日计划」整理草稿。窗口里可以翻前后一天，拖边缘调整大小（大小和位置会被记住），`Esc` 或 `⌘J` 关闭，和主窗口、笔记互不影响。主界面只有待办清单和月历。

## 三个入口

| 快捷键 | 功能 |
| --- | --- |
| `⌃N` | **笔记**（全局；标签右键可重命名 / 合并 / 删除（内容保留），都能 ⌘Z；Scheduler 里 `⌘N` 也行）：清单里选中了某条待办就直接打开它的笔记（还没笔记也能直接写），否则回到上次的位置。图片在独立窗口里查看，可拖动、调整大小，`←` `→` 在同一个待办的所有图片间切换。标签是笔记本，待办是里面的章节。可新建空标签、直接往标签里写，也可按待办或按日期查看；按待办看时右侧有章节目录，点一项跳到那一章，章节可折叠；每条笔记可复制、编辑、删除、更换关联待办。无标题栏按钮，`Esc` 或再按一次关闭。关闭后再打开（包括重启应用）回到上次的位置：选中的任务或标签、搜索词都还在；输入框里没发送的草稿（每个任务、每个标签各一份）在应用运行期间一直保留。各窗口互相独立，`⌃⌥D` 收起主窗口不影响它。 |
| `⌃⌥L` | **快速日志**：在任何应用里呼出，写一条日志（粘贴大段内容时输入框自动增高，`⇧回车` 换行；失焦、`Esc` 关闭后草稿仍在，下次呼出自动恢复，只有发送成功才清空），`@` 关联待办、`#` 选标签，`⌘V` 可贴图，`Tab` 切到快速添加待办。支持 `/done` `/block` `/plan` 开头，`#3` 开头关联任务。 |
| `⌃⌥T` | **内置终端**：zsh，可分栏、多标签。 |
| `⌃⌥F` | **专注工作台**：选择任务、设置本轮目标和时长；专注中显示常驻倒计时与快速笔记。 |

另有 `⌃⌥D` 显示 / 隐藏主窗口。切到别的应用时，主窗口、笔记、日志、终端、设置会立刻收起（内容、草稿、终端里的程序都保留，用快捷键或点 Dock 图标唤回；在 Scheduler 自己的窗口之间切换不算离开），快速日志面板和专注计时窗口不受影响；设置里可关。全局快捷键均可在设置里重新绑定（注意 `⌃N` 会占用其他应用里的同一组合键）。

笔记 / 日记快捷键在当前桌面唤起已有窗口，保留当前模式和日期，不会跳回之前的桌面；窗口已在当前桌面前台时，再按一次才关闭。

## 关联待办

写日志 / 笔记时，在输入框里输入 `@` 加几个字选待办、`#` 加几个字选标签（`#` 候选里也能直接新建；快速日志、笔记、当天日志窗口都支持），都会弹出候选：`↑ ↓` 选，回车或 `Tab` 确认，`Esc` 只关候选。能按标题、编号、`#标签`、拼音（`lunwen`）、拼音首字母（`lw`）找，漏字也行（`读文` → 读论文）。排序会猜你要写哪个：专注中的、固定的、带当前标签的、最近写过的在前。开头直接写 `#3` 也行。

笔记和日志正文原生渲染 Markdown：标题、粗体/斜体、删除线、链接、引用、有序/无序列表、任务列表、代码块和表格（支持列对齐、中文自动换行）。双击正文或点编辑按钮修改 Markdown 原文；复制整条记录也保留原文。HTML 按文字显示；Markdown 图片显示为可点击链接，粘贴的图片附件仍使用原有图片查看器。

专注流水保留秒级时间戳，以连续竖线和彩色节点显示：从 `FOCUS` 圆点到 `END` 圆点的连线为蓝色，其余为灰色。蓝色 `FOCUS` 记录计划时长与目标，青色 `NOTE` 是专注中的笔记，紫色 `REVIEW` 是阶段反馈，绿色 `END` 显示有效时长、结束原因和累计时长；进展、卡点、计划沿用 `DONE`、`BLOCK`、`PLAN`。`FOCUS`、`REVIEW`、`END` 仅在日记中展示，不计入待办和标签笔记；实际笔记仍保留在两处，正文完整展开。专注中不重复显示任务和标签，开始节点保留任务信息。复制和导出保留原始记录与目标。短专注如果填写了目标或阶段反馈，也会保留开始、结束记录；未填写时仍遵循设置中的最短记录时长。

**固定关联**：待办行、笔记标题上的图钉把它固定为「当前待办」，之后没指定时的日志都记到它名下，不计时；专注中仍优先，完成或删除后自动取消。输入框下面的关联条显示这条会记到哪，可一键「这条不关联」。

## 标签

写 `#论文` 或点 `#` 按钮打开标签浮窗：圆角标签排列，点选高亮，可输入新标签；点「保存」应用，点「取消」放弃修改。主界面和快速待办可在创建前选择标签；笔记／日记的消息条目也有 `#` 加标签、`@` 更换关联待办的按钮，快速日志使用同样的浮窗。标签不含空格，不区分大小写；纯数字 `#3` 是任务编号，不算标签；`论文/方法` 属于 `论文`。在笔记里点标签，或在搜索框输入 `#标签`，就能看到带该标签的所有待办及其笔记。点每条日志最右边的圆圈选中它，选中几条后日志区底部出现操作栏，可批量加 / 去标签，或批量关联到某个待办（一次 `⌘Z` 撤销整批）；日志自己的标签不依赖待办。标签可以先建成空的（笔记窗口「标签」旁的 +），之后在标签页底部直接写，不必关联待办。批量栏和各处的「关联待办」都是带搜索的选择器（标题、编号、`#标签`），专注中和最近用过的排最前。日志行、笔记行和批量栏都能一键复制文字（不含图片）。

## 命令行 `sched`

安装后在任何终端可用（zsh 里自带同名内置命令，请用 `scheduler`，或在 `~/.zshrc` 加 `disable sched`）。

```sh
sched logs [-t 3] [--tag 论文] [-g 关键词]   日志列表
sched notes 3 | 论文                          某个任务 / 标签的笔记
sched tasks / tags / status                   任务、标签、概况
sched todo --priority high "明天 15:00 开会"   创建高优先级任务
sched priority 3 low                         修改任务优先级
sched pick                                    交互式选择
sched log "内容" / todo "明天 开会" / done 3   写入（经运行中的应用，必要时自动启动）
```

读取不需要应用在运行，写入通过本机 socket 交给应用。`sched help` 查看全部用法。

## 安装

需要 Xcode 或 Swift 命令行工具：

```sh
bash scripts/install.sh
```

应用装到 `~/Applications/Scheduler.app`，命令行装到 `~/.local/bin`。更新前请先退出 Scheduler。运行测试：`swift test --disable-sandbox`。

## 数据

位于 `~/Library/Application Support/Dayleaf/`：`journal.json`（原子写入）、`Images/`，每日自动备份到 `Backups/`（保留最近 30 个）。菜单里可导出、从备份恢复。
