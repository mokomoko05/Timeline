# 日记 / 笔记：点击选择与编辑预备

## 交互与布局

macOS 的条目不再因鼠标经过而切换整行底色、显示操作栏或预备 WebKit。第一次点击正文选中，使用现有时间轴的淡强调色背景与左侧强调条，显示原有按钮；再次点击正文才编辑。链接、待办复选框、标题折叠和代码复制保留直接点击操作。鼠标选择不自动滚动，键盘选择仍滚动定位。

选中后延迟 40 ms 预备当前条目的编辑器，让选择状态先显示；预备不隐藏正文、不拿键盘焦点、不开始编辑。第二次点击可直接启用已经排好的编辑器；如果还没准备完，沿用正在进行的准备。切换条目、取消选择或滚动会取消待执行的准备，并释放已预备的条目；已加载的 WebKit 仍复用。

无元信息行的条目固定为右侧操作栏留位，避免删除按钮遮住标题折叠按钮及其扩大后的点击区域。选择前后正文宽度和行高不变，代价是这类条目的正文比原先略窄，长行可能增加换行。已有元信息行的条目继续使用原来的标题栏操作区域。

点击区域用原生视图记录，只有点击时查询，不发布滚动几何或监听鼠标移动。查询同时取 `bounds` 与 `visibleRect` 的交集：AppKit 的 `visibleRect` 可能超出不裁剪的视图边界，单独使用它会误认其他条目或空白区域。

## 编辑准备时间

Release、隐藏窗口，沿用编辑器对齐测试关闭 WebKit 的窗口遮挡检测，但不改变窗口透明度。测量的是本进程事件处理、布局与编辑器就绪时间，不是屏幕实际呈现或触控板输入延迟。

- 不预备时，第二次点击到编辑器就绪约 36～51 ms。
- 选中后预备完成时，两次相关测试分别为 4.17 ms、0.62 ms；首次选中到同步布局约 1.07～1.41 ms。
- 透明窗口保持 WebKit 默认遮挡行为时，约 0.53 秒的结果主要命中编辑器半秒兜底，不能用来代表正常显示时的等待。

这些是已经加载编辑器的简单条目测量。应用刚启动、极长正文或两次点击间隔短于准备时间时，仍需等待网页加载和排版；没有把这一等待宣称为已消除。

## 真实长数据滚动

使用上一轮冻结的真实数据副本，原文件不写入。Release、1424 × 876 隐藏窗口、1.1 倍字号、4500 pt/s、约 120 Hz 回调；每页向上、返回、再次向上。原生对照与四类页面串行运行。

新增点击区域的初稿使用默认原生视图尺寸推算，增加了同步布局成本。最终实现直接采用正文给定的尺寸；下表是这次修正前后，再次向上滚动的同步工作 p95，单位 ms，两版使用同一副本与路径。

| 页面 | 点击区域初稿 | 显式沿用正文尺寸 |
| --- | ---: | ---: |
| 49 条长日记 | 1.73 | 0.71 |
| 84 条日记 | 3.58 | 1.39 |
| 80 条图片笔记 | 4.14 | 2.33 |
| 33 条任务笔记 | 0.68 | 0.58 |

最终版首次 / 再次向上的 p95 与最大同步耗时如下：

| 页面 | 首次 p95 / 最大 ms | 再次 p95 / 最大 ms |
| --- | ---: | ---: |
| 长日记 | 0.75 / 1.18 | 0.71 / 1.08 |
| 84 条日记 | 1.42 / 1.78 | 1.39 / 1.78 |
| 图片笔记 | 2.35 / 3.03 | 2.33 / 3.04 |
| 任务笔记 | 0.63 / 0.87 | 0.58 / 0.95 |

四页三遍共 12 遍，移动帧同步工作超过 8.33 ms 的数量为 0。首次和再次向上也均无错过刷新机会、超过 50 ms 回调间隔或未完成主回调导致的 tick 合并。这些数字不等于屏幕实际 FPS，也没有模拟真实鼠标悬停或点击期间的滚动。

同步打开时间约为长日记 369 ms、84 条日记 323 ms、图片笔记 558 ms、任务笔记 149 ms，仍有首次构建成本。原始正文、图片、标签和记录标识未加入仓库。

## 验证范围

交互回归覆盖首次选中后仅预备、预备不抢焦点、再次点击编辑、取消选择与快速切换时取消准备、鼠标选择不触发滚动、空白区域取消选择、直接点击链接和折叠按钮，以及 72 / 96 pt 操作栏在三档字号、两种窗口宽度下与标题折叠点击区域分离。另运行编辑器对齐、日记编辑、键盘选择、折叠与滚动回归。测试使用隐藏窗口与 AAA / ZZ 守门，并独立监控窗口服务器。

最终相关测试 37 项通过；全量 Release 回归 724 项，22 项按条件跳过，零失败。真实长数据探针单独运行通过，窗口服务器两段监控日志均无可见测试窗口。全量回归中，预备后再次点击到编辑器就绪为 0.69 ms。
